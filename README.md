# Space Shooter 🚀

Unity ve C# kullanılarak geliştirilmiş, temel mekaniklere sahip basit bir space shooter oyunudur.

## Özellikler
* **Gemi Kontrolü:** Oyuncu uzay gemisini yön tuşları (veya WASD) ile kontrol eder.
* **Savaş Mekaniği:** Düşman gemilerine veya meteorlara lazer atışı yapma.
* **Düşman Dalgaları:** Ekranın üst kısmından sürekli olarak gelen düşmanlar.
* **Skor Sistemi:** Yok edilen her düşman için puan kazanma ve "Game Over" ekranı.
